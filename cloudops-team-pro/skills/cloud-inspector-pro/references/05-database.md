# 05 云数据库安全巡检

> SOP: TC-SEC-SOP-001 | 章节 05

## 5.1 访问控制

**风险等级：🔴 严重**

| 检查项 | 操作方法 | 判定标准 | 处置 |
|--------|---------|---------|------|
| 外网访问 | 实例 > 外网地址 | 默认关闭；开启须配安全组 | 关闭或配白名单 |
| 鉴权配置 | 实例配置 | 必须开启；禁免密（尤其 Redis）| 开启 + 强密码 |
| 密码强度 | 账号管理 | ≥ 12 位大小写 + 数字 + 特殊字符 | 重置为强密码 |
| 安全组 | 实例 > 安全组 | 必须绑定安全组 | 绑定并限源 IP |
| 账号权限 | 账号管理 > 权限 | 最小权限，禁 ALL PRIVILEGES | 收敛权限 |

### 巡检步骤

1. 登录云数据库控制台，导出所有实例列表
2. 检查每个实例的"外网访问"状态，非必要立即关闭
3. 对开启外网访问的实例，确认安全组白名单配置是否精确
4. 检查 Redis 实例是否开启了密码鉴权（严禁免密模式）
5. 进入账号管理，核查每个数据库账号的权限，收敛 ALL PRIVILEGES

## 5.2 数据保护

| 检查项 | 操作方法 | 判定标准 | 风险等级 |
|--------|---------|---------|---------|
| 自动备份 | 备份 > 策略 | 保留 ≥ **7天** | 🟠 高 |
| 备份加密 | 备份设置 | 敏感业务开启 | 🟡 中 |
| 审计日志 | 数据库审计 | 建议开启 | 🟡 中 |
| 慢查询 | 操作日志 | 建议开启监控 | 🟡 中 |
| 跨地域备份 | 备份 > 跨地域 | 核心业务开启 | 🟡 中 |

### 巡检步骤

1. 检查每个实例的自动备份策略，确认保留天数 ≥ 7 天
2. 核查核心业务数据库是否配置跨地域备份
3. 敏感业务数据库确认已开启数据库审计功能

## 5.3 各数据库特殊检查项

| 数据库 | 检查项 | 标准 |
|--------|--------|------|
| **MySQL** | Binlog | 生产必须开启 |
| **MySQL** | 半同步复制 | 核心业务建议开启 |
| **Redis** | 密码鉴权 | **严禁免密** |
| **Redis** | 高危命令 | 禁 FLUSHALL / FLUSHDB / KEYS |
| **Redis** | 大 Key 检测 | 定期检查大 Key |
| **MongoDB** | 匿名访问 | 必须开鉴权 |
| **MongoDB** | bind_ip | 禁止 0.0.0.0 |
| **PostgreSQL** | pg_hba.conf | 禁 0.0.0.0/0 无限制 |
| **Elasticsearch** | X-Pack | 建议开启用户认证 |

### Redis 专项巡检步骤

1. 检查 Redis 实例鉴权模式：进入实例 > 安全管理，确认已设置密码
2. 查看是否开启高危命令禁用（FLUSHALL/FLUSHDB/KEYS/RENAME）
3. 对外网暴露的 Redis 实例立即关闭外网访问
4. 使用云监控检查大 Key（内存占比 > 10% 的 Key 需评估优化）

### MongoDB 专项巡检步骤

1. 检查 MongoDB 实例是否关闭匿名访问
2. 确认 bind_ip 配置不为 0.0.0.0
3. 检查安全组，确认 27017 端口未对外网全开放
