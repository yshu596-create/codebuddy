# 04 COS 对象存储安全巡检

> SOP: TC-SEC-SOP-001 | 章节 04  
> 操作路径：COS > 存储桶列表 → https://console.cloud.tencent.com/cos

## 4.1 存储桶权限配置

**风险等级：🔴 严重**

| 检查项 | 操作方法 | 判定标准 | 处置 |
|--------|---------|---------|------|
| 访问权限 | 桶 > 权限管理 | 敏感数据 = 私有读写；禁止公有读写 | 改为私有读写 |
| 公有读写 | 桶 > 权限管理 | **严禁公有读写** | 改为私有读写 |
| 目录遍历 | 策略权限 / 匿名 | 禁止匿名 ListBucket | 移除匿名列目录权限 |

### 巡检步骤

1. 登录 https://console.cloud.tencent.com/cos/bucket
2. 导出所有存储桶列表，检查"权限类型"列
3. 对每个"公有读写"或"公有读私有写"的存储桶：
   - 确认业务用途
   - 不需要公开的立即改为"私有读写"
4. 进入每个存储桶 > 权限管理 > 存储桶策略
5. 检查是否存在 Principal: `*` 且 Action 包含 `cos:GetBucket`（ListBucket）的策略 → 移除

## 4.2 STS 临时密钥使用规范

**风险等级：🟠 高**  
前端直传 COS 场景必须使用 STS 临时密钥，禁止使用永久密钥。

| Policy 字段 | 要求 | 安全示例 |
|------------|------|---------|
| action | 具体接口（非 `*`） | `cos:PutObject` |
| resource | 具体桶 + 路径 | `qcs::cos:ap-gz:uid/xxx:bucket/upload/<userid>/*` |
| condition | 限制 content-type | `image/jpeg, image/png` |
| 有效期 | ≤ 1800 秒 | DurationSeconds: 900 |

### 巡检步骤

1. 核查所有前端直传 COS 的业务代码
2. 确认是否使用 STS 接口获取临时密钥
3. 检查 STS Policy 是否遵循最小权限（精确到桶路径和接口）
4. 检查 DurationSeconds 是否合理（建议 ≤ 1800 秒）

## 4.3 数据安全与备份

| 检查项 | 操作方法 | 判定标准 | 风险等级 |
|--------|---------|---------|---------|
| 服务端加密 | 加密配置 | 敏感桶开启 SSE-COS / KMS | 🟡 中 |
| 防盗链 | 安全管理 > 防盗链 | 对外下载桶配 Referer 白名单 | 🟡 中 |
| 版本控制 | 容错容灾 > 版本控制 | 核心数据桶开启 | 🟡 中 |
| 跨地域复制 | 容错容灾 > 桶复制 | 重要数据异地复制 | 🟡 中 |
| 日志管理 | 日志管理 | 敏感桶开启访问日志 | 🟡 中 |
| 生命周期 | 基本配置 > 生命周期 | 合理配置过期/降冷策略 | 🟡 中 |
| 预签名 URL | 代码审查 | 敏感文件下载用预签名 + 有效时间 | 🟡 中 |
| 盲水印 | 安全管理 | 身份证等敏感图片加盲水印 | 🟡 中 |

### 巡检步骤

1. 对每个存储桶，进入"安全管理"页面，逐项检查上述配置
2. 敏感数据桶（含身份证、合同、财务数据）须优先确保：
   - 开启 SSE-COS 或 KMS 加密
   - 开启访问日志
   - 开启防盗链
3. 核心业务桶确认已开启版本控制和跨地域复制
