# 08 中间件与大数据服务安全巡检

> SOP: TC-SEC-SOP-001 | 章节 08

## 8.1 Elasticsearch / Kibana

**风险等级：🔴 严重**

| 检查项 | 操作方法 | 判定标准 | 处置 |
|--------|---------|---------|------|
| ES 公网 | ES > 基本配置 | 关闭或配 IP 白名单 | 关闭/设白名单 |
| Kibana 公网 | ES > Kibana | 关闭或配白名单 | 关闭/限制 |
| X-Pack | ES > 安全配置 | 建议开启认证 | 开启 Basic 安全 |
| 匿名访问 | ES 配置 | 禁未鉴权访问 | 开启认证 |
| 索引权限 | X-Pack > 角色 | 按索引最小授权 | 配置角色权限 |

### 巡检步骤

1. 登录 ES 控制台，检查每个集群的公网访问状态
2. 对开启公网访问的 ES 实例，确认 IP 白名单是否精确
3. 检查 Kibana 公网访问，非必要关闭或限制 IP
4. 确认 X-Pack Basic Security 已开启，无匿名访问
5. 核查 ES 角色权限，确认按索引最小化授权

## 8.2 EMR 弹性 MapReduce

| 检查项 | 操作方法 | 判定标准 | 处置 |
|--------|---------|---------|------|
| Master 安全组 | EMR > Master CVM | 入站默认拒绝，按需加白 | 绑安全组 |
| 管理后台 | HDFS/YARN/Hue 端口 | 不应对公网暴露 | 安全组限内网 |
| Kerberos | EMR > 安全设置 | 核心集群建议开启 | 启用 Kerberos |
| Ranger | 权限管理 | 建议开启细粒度权限 | 接入 Ranger |

### 巡检步骤

1. 前往 EMR 控制台，检查每个集群的 Master 节点安全组
2. 核查以下端口是否对公网开放（应仅内网）：
   - HDFS NameNode: 50070/9870
   - YARN ResourceManager: 8088
   - Hue: 8888
   - Spark: 4040/8080
3. 核心 EMR 集群评估开启 Kerberos 认证
4. 评估接入 Ranger 实现细粒度权限管理

## 8.3 CKafka / API 网关 / 微服务

| 检查项 | 操作方法 | 判定标准 | 风险等级 |
|--------|---------|---------|---------|
| CKafka 鉴权 | 访问控制 | 开启 SASL | 🟠 高 |
| CKafka 公网 | 基础信息 | 非必要关闭 | 🟠 高 |
| CKafka ACL | 消费者组 | 按 Topic 最小化授权 | 🟠 高 |
| API 网关认证 | API 管理 | 所有 API 配认证 | 🟠 高 |
| API 网关限流 | 流量控制 | 配置合理限流策略 | 🟡 中 |
| Nacos/Apollo 公网 | 微服务引擎 | 管理台不对公网暴露 | 🟠 高 |
| ZooKeeper 鉴权 | 微服务引擎 | 开启 ACL 认证 | 🟠 高 |
| RabbitMQ 管理台 | 消息队列 | 管理台限内网 | 🟠 高 |

### 巡检步骤

1. **CKafka**：检查 SASL 鉴权是否开启，公网访问是否关闭，ACL 规则是否最小化
2. **API 网关**：检查每个 API 是否配置了认证（Key/OAuth/JWT），是否设置限流
3. **Nacos / Apollo**：确认配置中心管理台未对公网暴露
4. **ZooKeeper**：确认 ZooKeeper 集群已开启 ACL 认证（禁止 `world:anyone:acdrw`）
5. **RabbitMQ**：确认管理台（15672 端口）仅内网可访问
